# 사이트 설계도(PRD) — 마카롱 원데이 클래스 (사이트 이름 미정)

작성일: 2026-10-25 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
마카롱 원데이 클래스를 소개하고, 보고 마음에 든 손님이 수업 신청을 남기게 하는 사이트.

## 2. 손님
- 누가: 혼자 마카롱 만들기를 배우고 싶은 사람
- 어디서 알고 오나: 네이버 검색 (예: "마카롱 원데이 클래스")

## 3. 손님이 궁금한 것 (신청하기 전에)
1. 가격
2. 초보도 가능한지
3. 날짜·시간
4. 가져가는 것 (몇 개를 만들어 가져가는지)

## 4. 믿게 할 증거 (실제로 있는 것만)
- 마카롱·수업 사진 (사용자가 직접 찍은 실제 사진)
- 강사 자격·경력: (미정 — 말하지 않았으므로 넣지 않는다)
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 수업 신청하기
- 누르면: 수업 신청 폼

## 6. 페이지 구성 (위에서 아래로, 한 장짜리)
1. 첫 화면 — 한 문장 + [수업 신청하기] 버튼 + 대표 마카롱 사진
2. 수업 안내 — 가격 · 날짜·시간 · 가져가는 것 · 위치 (정해지면 채우고, 지금은 "준비 중")
3. 초보도 괜찮아요 — 처음인 사람이 걱정할 점에 대한 답 (수업 내용이 정해지면 사실만 적는다)
4. 사진 — 실제 마카롱·수업 사진
5. 후기 자리 (비워 둠)
6. 수업 신청 폼

## 7. 수업 신청 폼에서 받을 것
- 이름, 연락처
- 원하는 날짜
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: (미정)
- 날짜·시간: (미정)
- 위치: (미정)
- 가져가는 것: (미정)
- 연락 방법: (미정)
- 정해지기 전까지 사이트에는 지어내지 않고 "준비 중"으로 표시한다.

## 9. 이번에 넣지 않을 것
- 온라인 결제
- 회원가입·로그인
- 블로그·공지 게시판
- 손님 사진 올리기
- 신청 알림 메일

## 10. 첫 화면 한 문장 후보
1. 혼자 와도 괜찮아요, 처음 만드는 나만의 마카롱
2. 하루 만에 배우는 마카롱, 혼자 오셔도 돼요
3. 오늘은 마카롱을 직접 만들어 보는 날

## 11. 다음에 할 것
- 가격·날짜·시간·위치·가져가는 것·연락 방법 정하기 → 8번과 사이트 채우기
- 실제 수강 후기가 생기면 후기 자리 채우기
- 강사 소개(자격·경력)가 있으면 추가
- 네이버 검색에 잘 나오도록 사이트 제목·설명 다듬기, 네이버 서치어드바이저 등록

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 발랄한 · 참고 디자인: 없음 — 클로드가 정함
- 신청 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 수업 신청 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
